# Print Files for VPForce Joystick with 86BLF03 or 86BLF04 motors
See originial TheAmazinGrace and Gadroc designs for credits and design change history. 

The only thing I've added here is print files set up for Bambu printers.   These are the parts I used, oriented in the best way I could figure out for strength with minimal supports.   

I printed the case in Elegoo PETG HF because I wanted the maximum temperature tolerance that I could achieve on my open bed A1 printer next to those big motors.  

The gimbal and some of the outside parts were printed in Sunlu PLA + 2.0 for its rigidity and ease of printing.
